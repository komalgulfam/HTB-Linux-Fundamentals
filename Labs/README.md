# HTB Linux Fundamentals - Labs

## Overview

This folder contains the practical labs completed while studying the **Hack The Box Linux Fundamentals** module.

Each lab documents the hands-on tasks performed during the exercises, including the commands used, observations, and lessons learned.

## Lab Structure

Each lab typically includes:

- Objective
- Environment
- Tasks Performed
- Commands Used
- Results
- What I Learned
- Screenshots (if available)

## Available Labs

- Lab 01 - User Management
- Lab 02 - Networking
- Lab 03 - Firewall
- Lab 04 - Logging
- Lab 05 - Services
- Lab 06 - Docker
- Lab 07 - LXC
- Lab 08 - Storage
- Lab 09 - File Transfer
