# Linux Commands

## File Management

| Command | Description |
|---------|-------------|
| pwd | Show current directory |
| ls | List files and directories |
| cd | Change directory |
| cp | Copy files |
| mv | Move or rename files |
| rm | Remove files |
| mkdir | Create directory |

---

## Permissions

| Command | Description |
|---------|-------------|
| chmod | Change file permissions |
| chown | Change file owner |

---

## Search

| Command | Description |
|---------|-------------|
| find | Search files |
| grep | Search text |

---

## Editors

| Command | Description |
|---------|-------------|
| nano | Open text editor |
| cat | Display file contents |
